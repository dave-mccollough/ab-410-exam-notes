# AB-410 Notes

- Environments
  - Allow you to store, manage and share data, apps and flows within the Power Platform 
  - Use different environment for 
    - Different geographic regions
    - Different purposes (dev, test, prod)
    - Different departments
  - Enviornment Types
    - Default Environment
      - Automatically created when you create your Power Platform Environment
    - Production 
      - Production work
      - 1Gb database capacity
    - Sandbox
      - Development and testing
    - Trial
      - Short term environment and will expire after 30 days
    - Trial (Subscription Based)
      - Used for larger trials
        - Multi user
        - Multi department trials
      - End data that can be extended
    - Developer
      - Use if you have a developer plan
      - Only for use by the owner
  - Regions
    - Select region where data will reside
      - Data sovereignty
    - Not all features are available in all regions
  
  - Solutions
    - Solutions allow you migrate apps and components from one environment to another
    - Allow you to group together similar objects

- Canvas Apps
  - Canvas app: You design how the app looks and works, arranging buttons, fields, and screens yourself.
    - Example: A simple app where an employee takes a photo and reports broken equipment.

- Model Driven
  - Model-driven app: You define the information you need to manage and how it connects. Power Apps builds much of the interface for you.
    - Example: A system for managing equipment, employees, and maintenance requests.
